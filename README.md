# Room Booking System

Мини-система бронирования переговорных комнат.
REST API на Spring Boot + SPA на Vue 3.

## Стек технологий

**Backend:**
- Java 26+ / Spring Boot 4
- Spring Web (REST), Spring Data JPA
- PostgreSQL 18 (Docker)
- Lombok, Bean Validation, Swagger UI

**Frontend:**
- Vue 3 + Vite
- Vue Router 4, Pinia, Axios

## Требования

- Docker Desktop
- JDK 26+
- Node.js 20+

## Игры

В карточке **Games** на главной доступны две игры, обе считают очки
и показывают их в профиле.

**Minesweeper** — одиночная, поле 9×9. Победа записывается на сервер:
клиент присылает только время и число верных флажков, очки считает бэкенд
(`POST /api/games/minesweeper`).

**Battleship** — на двоих, поле 6×6, флот 3 + 2 + 2 + 1 + 1 + 1 = 10 клеток.
Классические правила: между кораблями должна оставаться хотя бы одна пустая
клетка (и по диагонали тоже), а за попадание в корабль игрок стреляет ещё раз,
пока не промахнётся.
Первый игрок создаёт сессию и ждёт, второй видит открытые сессии в лобби
и присоединяется к любой. Флот сохраняется между партиями, поэтому
в следующий раз можно начать сразу.

Очки: 20 за каждую клетку потопленного корабля, затем коэффициент исхода —
1.5 за победу, 0.5 за поражение. Победа со всем флотом даёт 300 очков.

### Как это устроено

Партия идёт по сокету `/ws/games` — в отличие от `/ws/rooms`, он
двусторонний: принимает ходы и адресно шлёт снимки конкретным игрокам,
потому что флот соперника не должен утекать. Личность игрока берётся
из `?token=` в адресе подключения: браузер при апгрейде на WebSocket
не умеет слать заголовки. Без валидного токена соединение закрывается.

Как и для комнат, клиенту уходит не дельта, а полный снимок состояния —
у каждого игрока он свой. Сессии живут в памяти и не сохраняются:
недосыгранную партию восстанавливать незачем, в базе остаются только
очки и последняя расстановка кораблей.

REST: `GET /api/games/stats`, `POST /api/games/minesweeper`,
`GET|PUT /api/games/fleet`, `GET /api/games/fleet/random`.

## Запуск

Нужно **3 терминала**.

### 1. База данных

Из **корня** проекта:
```bash
docker compose up -d postgres
```

### 2. Бэкэнд

Из папки **backend/**:
```bash
./mvnw spring-boot:run
```

### 3. Фронтенд

Из папки **frontend/**:
```bash
npm install   # только в первый раз
npm run dev
```

Открыть: http://localhost:5173
